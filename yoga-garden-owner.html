What changes behind the scenes?

This demo stores changes in your browser so the pages can talk to one another.

The real build would move that data to a backend such as Supabase: secure logins, database records, role permissions, waivers, bookings, and live updates. At this studio’s starting scale, we can begin with a free/low-cost setup rather than forcing a monthly custom-backend bill.
