Farmhouse & Fields Project Proposal

Farmhouse & Fields is already a busy, established daycare. The goal here is not to build a website that chases more leads. It is to create a warm, clear home base for the business you already have, connect clients cleanly to Time To Pet, and use the matched project value to make the wait-list and new-client handoff easier to manage.

01   The Website

A custom multi-page website that makes it easy to understand the daycare, find answers, and get to the right place quickly.

  • Custom design and mobile-friendly build
  • Copy shaping, page structure, services, pricing, About, FAQs, and clear calls to action
  • Time To Pet client portal connection for booking/service requests, client login, invoices, and payment
  • Clear separation between existing-client actions and prospective-client next steps
  • Basic on-page SEO, domain connection, Cloudflare hosting setup, and launch

What “Time To Pet connection” means
Time To Pet remains the system used for client accounts, scheduling, invoicing, and payment. The website will create clear, intentional pathways into it rather than rebuild or embed the platform itself.

02   The Match · +$900 Included

Recommended: Wait-list + Welcome

Your TYFD project match adds $900 in complementary work at no additional cost, focused on creating a simple wait-list and onboarding flow before clients move into Time To Pet.

  • Private wait-list dashboard with availability, notes, and status tracking
  • Guided onboarding questions to learn more about each dog when space becomes available
  • Wait-list communications for confirmation, openings, and next steps
  • One polished client guide, such as What to Know Before Daycare

The match stays flexible, so we can shift a piece if something else would be more useful during the build.
