What this could become

The Yoga Garden, all in one place.

A refreshed website and simple booking system built around the way the studio already works, without forcing The Yoga Garden into a large monthly booking platform.

For clients

Easy booking

  • Create a client profile once
  • Complete and track waiver status
  • See class availability
  • Book and cancel online
  • Join a cancellation list when full
  • Receive automated spot offers
For The Yoga Garden

Simple studio management

  • Owner and coach dashboards
  • Class rosters and capacity
  • Waiver status at a glance
  • Cash and e-transfer tracking
  • Attendance tracking
  • Manage classes without touching code
Optional later

Room to grow

  • Online payments
  • Class passes or packages
  • Memberships
  • Gift cards
  • More detailed reporting
Concept pricing

Two ways to approach it.

Final scope and price would be confirmed before any production work begins.

Booking system + portal $2,600 Built to work alongside the current website.
Website + complete booking system $3,400 Custom website, integrated classes, client portal, owner and coach dashboards.
Ongoing costs

At The Yoga Garden’s current size, the production system can be designed around infrastructure with free usage levels that should comfortably support the studio. There is no mandatory monthly hosting or maintenance package in this concept. Launch support is included, and future changes or new features can be quoted only when they are actually needed. Online payment can be added as an optional feature.
